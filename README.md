- What the first working slice allows a user to do
- A link or simple instructions for opening the prototype

- Your three test results
- Your known limitations

You do not need to submit:

- A revised PRD
- A separate testing document
- A complete prompt transcript
- A detailed technical architecture
- Screenshots unless they help explain a problem
